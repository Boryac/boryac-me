# media/ —— 档案示例图

每条档案的「示例图」放这里，线上路径就是 `/media/<id>/NN.jpg`。

## 命名与规格（硬约定，谁都不能改）

```
media/x001/01.jpg     主图：放版式右栏 + 三维卡片裁切源
media/x001/02.jpg     数据图 / 细节图
media/x001/03.jpg     可选第三张
```

- 目录名 = 档案 id 全小写（`X-017` → `x017`）
- 文件号从 `01` 开始，连续、不自造名字
- 尺寸 **2000×1250**（16:10），JPEG，质量 82，单张 ≤ 400 KB
- 主图（01）必须在 2000×1250 画布**四周留 0 边**、内容直接铺满（版式里会按比例裁切）
- 图上不得出现：第三方公司 logo、平台水印、真实姓名、手机号、二维码
- 图上允许出现：我们自己的品牌（BORV）、虚构的编号（X-001）、真实的量化数字

## 两类来源

- `media/<id>/` 由**真实截图**构成（弈康、borv 站点、AutoBookForge、影像抽帧、论文插图）
- `media/<id>/` 由**构造图**构成（把档案里的流程/数据做成界面或图表再截图）

两类目录名一致，唯一的区别是内容来源；不要另建 `gen/`、`real/` 子目录。
